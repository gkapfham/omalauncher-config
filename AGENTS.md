# omalauncher

This Arch system runs inside an Android launcher, omalauncher; its source is at https://github.com/SimonSchubert/omalauncher, should you need to understand how the launcher works. Home-screen widgets are `.owl` files in ~/.config/omalauncher/widgets, written in a small declarative language documented in README.md there (and docs/ next to it); so are apps for the app drawer (`app "name" { }`) and panels that swiping up or down on home opens (`panel "name" { }`, picked with gestures.swipe-up and gestures.swipe-down in ~/.config/omalauncher/style/style.toml). The app drawer is the panel drawer.owl there: to change the drawer, edit it; .stock-drawer.owl is the drawer as this launcher ships it. Likewise keybar.owl (`keybar "name" { }`) is the terminal key bar over the soft keyboard while typing in a terminal, and .stock-keybar.owl the bar as shipped. Saved files show up on the phone within seconds. After saving, run `owl-check <file>`: it prints the errors and the path of a PNG of the tile or view, drawn with live data; look at it to check the layout. examples/ holds more widgets to learn from or move up to use. Scripts, cron jobs and hooks can set a running widget's state or refresh it with `owl-send <file> set <state> <value>` and `owl-send <file> refresh`.

The launcher's look (theme, background, tile spacing and borders, corners, the system bars' colors, the terminals' font) is ~/.config/omalauncher/style/style.toml; defaults.toml next to it lists every setting with its default and range. Changes show within a second; errors.txt there says what was ignored and why.

Where everything on home is (pages in order, faces, widgets, pinned apps and folders, each tile's cell) is ~/.config/omalauncher/home/layout.toml; edit it to move, resize or pin things or reorder pages. docs/home.md in the widgets folder explains it.
